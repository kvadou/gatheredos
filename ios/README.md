# GatheredOS iOS

Native SwiftUI app (iOS/iPadOS 17+) hitting the same Supabase backend as the web app. Compact-width windows use the five-section tab bar; regular-width iPad windows use a sidebar and centered, readable content widths. Both orientations and iPad multitasking are supported. The project file is generated with [XcodeGen](https://github.com/yonaskolb/XcodeGen) from `project.yml`, so `GatheredOS.xcodeproj` is disposable — regenerate it any time with `cd ios && xcodegen generate`. The only Swift package dependency is [supabase-swift](https://github.com/supabase/supabase-swift), resolved automatically by Xcode/SPM on first build. Source lives under `ios/GatheredOS/`: a thin `SupabaseService` (client + async queries), plain Codable models (`Item`, `Home`, `CareTask`), and one SwiftUI view per screen (`AuthView`, `HomeView`, `LibraryView`, `ItemDetailView`, `AddItemView`). Brand colors are in `Assets.xcassets` with light + dark variants so no hex appears in view code.

To open in Xcode: `cd ios && xcodegen generate && open GatheredOS.xcodeproj`, then pick an iPhone or iPad simulator and hit Run. To build headlessly: `cd ios && xcodegen generate && xcodebuild -project GatheredOS.xcodeproj -scheme GatheredOS -destination 'generic/platform=iOS Simulator' build`. Auth uses email/password against Supabase and the session persists across launches. The Supabase URL and public anon key are baked into `Config.swift` (safe to ship — row-level security enforces access), so no `.env` or secrets setup is required to run.
